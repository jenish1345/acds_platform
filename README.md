# ACDS: Autonomous Company Diagnostic System

An executive dashboard for senior management to monitor company health, surface risks and support data-driven decisions. Built with TypeScript and a responsive UI, using simulated enterprise data.

- 8 screens covering company health, risk and decision support
- Documentation for the design system, deployment (Netlify) and executive user guide

The application and all documentation live in [`acds-platform`](acds-platform). Start with [`PROJECT_SUMMARY.md`](acds-platform/PROJECT_SUMMARY.md).
